# 鸿创工作室后台（hongchuang-admin）

## 技术栈
- Vue 3
- Vite
- TypeScript
- Pinia
- Vue Router
- Element Plus

## 已包含页面
- 后台登录
- 仪表盘
- 用户管理
- 帖子管理
- 评论管理
- 板块管理
- 标签管理
- 举报处理
- 公告管理
- 资源管理
- 资源分类管理

## 运行
```bash
npm install
npm run dev
```

## 构建
```bash
npm run build
```


## 调试验证码显示
开发环境可通过 `VITE_SHOW_DEBUG_CODE=true` 显示调试验证码；生产环境请保持 `false`。
